# Module sz-kotlin-sdk

An unofficial Kotlin SDK for Senzing V4 entity resolution, for the JVM and Android.

# Package io.github.brianmacy.sz

The public interfaces, flags, exceptions, logging types, the coroutine engine and the typed calls.

# Package io.github.brianmacy.sz.core

The implementations over the native engine, starting with SzCoreEnvironment.

# Package io.github.brianmacy.sz.models

kotlinx.serialization models of the engine's JSON results.
